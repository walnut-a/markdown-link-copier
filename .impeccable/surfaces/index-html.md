# Markdown Link Copier website surface brief

- Audience: people who collect and share web links in Markdown notes, documentation, blogs, knowledge bases, and chats.
- Goal: make the one-click copy experience immediately understandable, then prove that the extension is unusually small, private, carefully tested, and open source.
- Chosen structure: Open-source ledger. The copy transformation stays visually dominant while every trust claim sits beside verifiable evidence.
- Visual language: pale blue daylight, dark ink typography, Chrome-blue actions, success green, thin technical rules, and the real MD icon.
- First viewport: concise promise and install CTA on the left; real browser and extension UI on the right; a proof rail underneath with 44 KB, Manifest V3, 42 tests, and no data collection.
- Story: copy moment -> cleanup logic -> permission ledger -> open-source proof -> install.
- Constraints: static HTML/CSS/JS, no external runtime dependencies, responsive, keyboard accessible, reduced-motion friendly, GitHub Pages ready.
