# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain static HTML, CSS, and JavaScript. The product site is intended for GitHub Pages and must not add a runtime framework or third-party application dependency.

## Users

People who regularly capture, write, or share web links in Markdown-based notes, documentation, blogs, knowledge bases, and chats.

## Product Purpose

Markdown Link Copier turns the current page into a clean, accurate, Markdown-ready link in one deliberate action. Success means the copied result is immediately trustworthy and needs no manual cleanup.

## Positioning

The extension combines careful article-title extraction, conservative tracking-parameter removal, same-site canonical URL handling, configurable output, and visible result verification in a very small local-only package.

## Operating Context

Users invoke the extension from the Chrome toolbar or a keyboard shortcut while reading a page, then paste the result into another writing or knowledge tool. Settings are optional and the primary copy path stays automatic.

## Capabilities and Constraints

- Manifest V3 Chrome extension with a narrow link-copying purpose.
- Default Markdown output plus built-in presets and custom templates.
- Title extraction from JSON-LD, Open Graph, article headings, metadata, and safe fallbacks.
- Conservative URL cleanup that removes known tracking parameters while preserving parameters that may affect page behavior.
- English and Simplified Chinese UI.
- No account, remote service, analytics, ads, or sale of browsing data.
- Minimum practical permissions and zero runtime third-party dependencies.
- The public website must remain fast, accessible, responsive, and deployable directly from the repository root.

## Brand Commitments

- Product name: Markdown Link Copier.
- Existing blue `MD` app icon remains the primary recognition asset.
- Voice is concise, factual, calm, and transparent.
- The website and store assets inherit the clear light-blue visual system established by the current extension UI and the 1280×800 store screenshot.

## Evidence on Hand

- Published Chrome Web Store listing and install link.
- Public source repository at `https://github.com/walnut-a/markdown-link-copier`.
- Version 1.5.3 package is approximately 44 KB compressed.
- Automated extension test suite and real-browser verification flows.
- Real interface assets under `chrome-extension/` and store artwork under `docs/store-assets/`.
- No testimonials, awards, large-user claims, or independent benchmarks are available and none should be invented.

## Product Principles

1. One action should produce a result the user can trust.
2. Preserve page meaning while removing only known link clutter.
3. Keep privacy, permissions, package size, and dependency footprint visibly small.
4. Show proof through the real interface and verifiable implementation details.
5. Keep advanced customization available without slowing the default path.

## Accessibility & Inclusion

The extension and product site should support keyboard navigation, visible focus, reduced motion, readable contrast, semantic structure, and responsive layouts.
